# 需求文档（AgentsWorldSystem）

> 文档定位：阶段性、可交付的工程需求与验收方式，方便与 EntelechySystem（ES）协同开发。

## 1. 背景与目标

AgentsWorldSystem 旨在提供多智能体世界环境的实现（可用于训练与研究），并能与 ES 的算法模块联通进行联合实验。

## 2. 目标用户与场景

- 研究者：运行环境以对算法进行评估与对比。
- 开发者：扩展新环境、实现前端可视化或做跨语言集成。

## 3. 功能需求（FR）

FR-1 可执行演示
- 提供至少一个可运行的演示（Python 后端 + React 前端 PoC），支持浏览器与 Electron 桌面运行。

FR-2 跨语言联通
- 提供桥接服务（WebSocket/HTTP/gRPC）示例，使前端或 Node 服务能与 Python 算法交互。

FR-3 统一前端栈
- 每个独立环境的前端建议使用 React + pnpm + TypeScript，并支持使用 Electron 打包。

## 4. 非功能需求（NFR）

- 可复现：通过 `pnpm` 和 Python 虚拟环境能在新机器上复现演示。
- 可维护：前端统一 `pnpm`，并提供打包与构建说明。
- 可审计：重要配置与运行快照应保存以便审计。

## 5. 验收标准

- 成功运行一个端到端 demo：React 浏览器前端或 Electron 桌面应用能完成一次 `reset -> step -> observe -> render` 交互。
- 提供桥接示例代码与 schema（JSON Schema 或 proto）并加入仓库示例目录。

## 6. 优先级与里程碑

- M1（短期）：完成 PoC（React + pnpm + TypeScript 前端 + WebSocket 桥接 + Python 后端）。
- M2（中期）：Electron 打包与 Docker 化部署示例；完善 schema 与测试。
- M3（长期）：支持 gRPC 高性能通道与 CI 集成的回归测试。
