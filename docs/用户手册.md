# 用户手册（AgentsWorldSystem）

> 文档定位：面向使用者/研究者，说明如何快速运行示例、在哪儿修改环境、如何查看输出。

## 快速开始（Windows）

1. 克隆仓库并进入目录。
2. 创建并激活 Python 虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
```

3. 安装 Python 依赖（若仓库提供 `requirements.txt` 或 `pyproject.toml`）：

```powershell
pip install -r requirements.txt
```

4. 运行 Python 示例（若存在）：

```powershell
python AgentsWorldSystem_python\main.py
```

## 前端演示（若存在 React 前端）

- 安装 pnpm：

```bash
npm install -g pnpm
```

- 进入前端目录后：

```bash
pnpm install
pnpm dev
```

- 若要运行 Electron 桌面版（示例脚本）：

```bash
pnpm electron:dev
pnpm electron:build
```

## 配置与输入/输出位置

- 项目不同子模块可能有各自的配置文件（例如 `AgentsWorldSystem_python` 下的配置）。
- 前端输出或日志通常在前端工程的 `dist` 或 Electron 构建输出目录中。

## 常见问题

- 依赖安装失败：检查 Python 版本与本地编译环境（尤其 Rust/Unity 组件）。
- 前端无法启动：确认已安装 `pnpm` 并使用 `pnpm install`。
